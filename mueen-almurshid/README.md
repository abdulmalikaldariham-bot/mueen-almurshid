# مُعين المرشد

مولّد أسئلة مساعدة للمرشد المهني. يكتب المرشد حالة المسترشد، فتقترح الأداة 15 سؤالًا تساعده على إدارة الحوار. الأداة لا تشخّص ولا تقرر عن المسترشد.

## التشغيل

يتطلب Node.js 20 أو أحدث.

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`.

للنشر على Vercel: ارفع المجلد إلى مستودع GitHub واربطه بـ Vercel، ولا يلزم أي إعداد إضافي.

## مفتاح الـ API

الموقع يعمل الآن دون مفتاح، ويعتمد على بنك أسئلة تجريبي (يظهر وسم «من البنك التجريبي» فوق النتائج).

لتفعيل التوليد بالذكاء الاصطناعي:

1. انسخ `.env.example` باسم `.env.local`.
2. ضع المفتاح في `ANTHROPIC_API_KEY`.
3. أعد تشغيل `npm run dev`.

على Vercel أضف المتغير نفسه من Settings ← Environment Variables ثم أعد النشر.

المفتاح يُقرأ في ملف واحد فقط يعمل في الخادم: `lib/generator/aiClient.ts`. المتصفح يتصل بـ `/api/questions` ولا يرى المفتاح. لا تضف `NEXT_PUBLIC_` إلى اسم المتغير.

الملف مكتوب لواجهة Anthropic. اسم النموذج الافتراضي في أعلى الملف، ويمكن تغييره بالمتغير `AI_MODEL`؛ تحقق من الاسم الحالي في https://docs.claude.com. لاستخدام مزوّد آخر عدّل هذا الملف فقط.

إذا فشل الاتصال بالنموذج تعود الأداة تلقائيًا إلى البنك التجريبي وتعرض تنبيهًا.

## بنية المشروع

```
app/
  page.tsx                  الصفحة الوحيدة
  layout.tsx                RTL والخط
  globals.css               كل الأنماط والألوان (متغيرات في :root)
  api/questions/route.ts    نقطة الاتصال: generate | replace | followUp
components/
  MueenApp.tsx              يجمع المكونات
  CaseInput.tsx             إدخال الحالة
  ModeSelector.tsx          اختيار نمط الأسئلة
  QuestionList.tsx          القائمة مقسّمة بمراحل الحوار
  QuestionCard.tsx          بطاقة السؤال (نسخ، استبدال، متابعة، تعديل)
  ResultsActions.tsx        أزرار أسفل القائمة
  Disclaimer.tsx            التنبيه المهني
hooks/
  useQuestionSession.ts     حالة الجلسة ومنطق التوليد والاستبدال والمتابعة
lib/
  types.ts                  الأنواع المشتركة
  modes.ts                  الأنماط والأغراض والمراحل ونصوصها
  clipboard.ts              النسخ
  validation.ts             التحقق من المدخلات في الخادم
  services/questionService.ts   اتصال المتصفح بـ /api/questions
  generator/
    engine.ts               يختار بين النموذج والبنك التجريبي
    aiClient.ts             ← مكان مفتاح الـ API
    prompts.ts              ← قواعد توليد الأسئلة المرسلة للنموذج
    analyzeCase.ts          التحليل الداخلي للحالة (لا يُعرض)
    plan.ts                 توزيع الـ 15 سؤالًا حسب النمط
    questionBank.ts         Mock Data: بنك الأسئلة
    mockProvider.ts         Mock Logic: الاختيار من البنك
    parse.ts                التحقق من رد النموذج
```

## أين تعدّل

| المطلوب | الملف |
| --- | --- |
| قواعد صياغة الأسئلة | `lib/generator/prompts.ts` |
| توزيع الأسئلة لكل نمط | `lib/generator/plan.ts` |
| إضافة نمط أو تغيير تسمية | `lib/modes.ts` |
| أسئلة البنك التجريبي | `lib/generator/questionBank.ts` |
| الألوان والخط | `app/globals.css` |

## الإضافات القادمة

- **تسجيل الدخول:** التحقق من هوية المرشد يوضع في `app/api/questions/route.ts` قبل تنفيذ الطلب.
- **حفظ الحالات والأسئلة المفضلة وسجل الجلسات:** أضف خدمة تخزين بجانب `lib/services/questionService.ts` واستدعها من `hooks/useQuestionSession.ts` بعد نجاح التوليد.
- **أدوات إرشاد أخرى:** كل أداة صفحة جديدة داخل `app/` بمكوناتها، وتشترك في `lib/` والأنماط.

## قبل النشر العام

- مسار `/api/questions` مفتوح. بعد إضافة المفتاح يستطيع أي زائر استهلاك الرصيد، فأضف تسجيل الدخول أو حدًّا لعدد الطلبات أولًا.
- عند تفعيل الذكاء الاصطناعي يُرسل وصف الحالة إلى مزوّد النموذج. الأداة تنبّه المرشد إلى عدم كتابة اسم المسترشد أو بيانات تعرّف به، ويحسن ذكر ذلك في سياسة الاستخدام.
- البنك التجريبي يعتمد على كلمات مفتاحية في الوصف، فأسئلته أعم من أسئلة النموذج، وأسئلة المتابعة فيه عامة وليست مبنية على نص السؤال.
